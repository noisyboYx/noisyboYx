Sorter de Amigo Secreto
Este projeto é uma ferramenta simples para organizar e sortear os amigos secretos de forma automatizada e sem complicação. Ideal para grupos de amigos, familiares ou colegas de trabalho que desejam realizar o tradicional amigo secreto de maneira mais prática e divertida!

Como funciona?
O sorter usa um algoritmo para sortear os pares de amigo secreto de forma aleatória e garantir que ninguém tire a si mesmo. Ao inserir uma lista de participantes, o sistema distribui os nomes de forma justa e confidencial.

Funcionalidades
Sorteio aleatório de pares de amigo secreto.
Garantia de que ninguém tirará a si mesmo.
Exibição das combinações de forma simples e clara.
Opção de gerar e exportar a lista de sorteio para diferentes formatos (como .txt ou .csv).
